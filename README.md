# 桌面研究助手-网页链接抓取 desk research helper - weburl collector

## 背景 
 战略的桌面研究（desk research）里，很大一部分是：特定网站里，关键词收集网页链接，之后批量盘查、去伪存真，得出有效情报结论。 
 
 因为“特定网站里，根据关键词，收集网页链接”可以批量化，所以在2019年设计了第一版脚本，2026年更新了第二版脚本。
 - 2019年 第一版：用chromedriver规避的方案，批量访问并获取文本，然后做nlp分析
 - 2026年 第二版：用selenium自带规避的方案，批量获取url，然后自行结合LLM AI使用

## 价值说明
 一个简单的自用小工具，帮忙提供一批知识边界，提升LLM使用体验，规避LLM自行寻找资料时来源垃圾的坑。
 
## 使用方法
 环境：python IDE
 
 输入：list1 关键词，list2 网站
 
 输出：合适网页的url list

## 注意
 1. “依赖于‘特定可靠公开信源’的desk research”本身的限制性无法解决
 2. LLM或无法访问部分网页
