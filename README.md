# 桌面研究助手-网页链接抓取 desk research helper - URL collector

## 背景 
 战略的桌面研究（desk research）里，很大一部分是：在特定网站里，关键词批量命中网页，之后大量阅读、去伪存真，得出有效情报结论。 
 
 因为“特定网站里，关键词批量命中网页”可以工具化，所以在2019年设计了第一版脚本，在2026年更新了第二版脚本。
 - 2019年 第一版：用chromedriver规避的方案，批量访问并获取文本，然后做nlp分析
 - 2026年 第二版：用Selenium自带规避的方案，在搜索引擎里批量请求并获取url，然后自行结合LLM AI使用

## 价值说明
 一个简单的自用小工具，帮忙提供一批知识边界，提升LLM使用体验，规避LLM自行寻找资料时来源垃圾的坑。
 
## 使用方法
 环境：python IDE
 
 输入：list1 关键词，list2 网站
 
 输出：合适网页的url list

## 用例
 假设你正在研究中国网盘行业的竞争格局与商业模式，希望从 36氪、虎嗅、晚点等科技商业媒体中，搜集有关百度网盘、阿里云盘及云存储行业的报道。

### 配置
 
 KEYWORDS = [
    "网盘",
    "云存储",
    "百度网盘",
    "阿里云盘"
]

WEBSITES = [
    "36kr.com",
    "huxiu.com",
    "latepost.com"
]

ENGINE = "google"

MAX_RESULTS_PER_QUERY = 20

### 过程
程序将关键词与网站进行两两组合，并通过 Google 执行搜索。

网盘 site:36kr.com，云存储 site:36kr.com，百度网盘 site:huxiu.com...

在这个例子中，4 个关键词 × 3 个网站，共生成 12 组搜索任务。每组任务尝试收集搜索引擎排名靠前的 20 条结果，总计最多获得 240 条搜索记录（不同任务可能命中相同网页）。

### 产出
每条结果记录：搜索关键词及目标网站，搜索结果排名，网页标题（Title），搜索摘要（Snippet），原始网页链接（URL）。程序自动整理搜索结果，并生成结构化数据文件及去重后的 URL 列表。

## 注意
 1. “依赖于‘特定可靠公开信源’的desk research”本身的限制性无法解决
 2. 结果里的部分网页，LLM或无法访问
